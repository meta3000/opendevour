# Code Review Skill

一个用于**代码评审**的示例 skill，演示 Skills 工作区对 Markdown 的预览与编辑。

## 用途

- 对提交的变更做结构化评审：正确性、可维护性、性能。
- 输出按维度分组的评审意见。

## 文件

| 文件 | 说明 |
|---|---|
| `review.py` | 评审主流程（Python） |
| `queries.sql` | 拉取待评审变更的 SQL |

## 评审清单

1. 是否有空指针 / 边界条件遗漏
2. 是否复用了已有工具函数
3. 是否有重复代码可以抽取
4. 关键路径是否有测试覆盖

> 提示：公共 skill 为只读，点击「复制到我的 Skills」后即可在「我的 skills」中编辑。
