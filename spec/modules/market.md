# 市场发现 - 详细设计

## 概述

市场发现模块提供全市场扫描能力，通过多种发现策略（因子、技术、基本面、事件）识别投资机会，并允许用户将发现的信号直接推送至智能驾驶舱进行深度分析。

## 布局结构

```
┌─ Topbar 52px ──────────────────────────────────────────────┐
│ 市场发现  │  策略选择器  时间范围  刷新  [发送至驾驶舱]     │
└────────────────────────────────────────────────────────────┘
┌─ 热力图区 flex:1 ─────────┐ ┌─ 侧边 320px ───────────────┐
│  市场全景热力图             │ │  板块轮动（Radar/Bar切换）  │
│  G2 Treemap                │ ├─────────────────────────────┤
│  面积=市值，色=涨跌幅       │ │  板块资金流向（Bar横向）    │
│  点击节点→选中股票          │ │                             │
└──────────────────────────┘ └─────────────────────────────┘
┌─ 信号表格区 ───────────────────────────────────────────────┐
│  信号扫描列表（Table，支持排序/筛选，置信度进度条，→驾驶舱）│
└────────────────────────────────────────────────────────────┘
```

## 热力图（HeatmapChart）

- **图表类型**：G2 Treemap（矩形树图）
- **数据**：40支 A 股，按市值决定节点面积
- **颜色映射**：
  - 绿色（`#00C896`）→ 涨幅 +7%+
  - 中性（`#2A2F3E`）→ 平盘附近
  - 红色（`#FF4D6A`）→ 跌幅 -7%-
- **节点标签**：公司简称 + 涨跌幅百分比
- **交互**：点击节点选中股票，顶部出现"发送至驾驶舱"按钮

## 板块轮动（SectorRadar）

### 雷达图模式（默认）
- 8个板块，两个维度：动量得分 + 估值得分（0–1）
- 两条折线（绿色=动量，橙色=估值），填充半透明

### 柱状图模式
- Segmented 切换
- 8个板块今日涨跌幅排行
- 颜色语义：涨绿跌红

## 资金流向（CapitalFlow）

- **图表类型**：G2 横向 Interval（条形图）
- **数据**：8个板块净流入额（亿元），已按净流入排序
- **颜色**：净流入 > 0 → `#00C896`，< 0 → `#FF4D6A`
- **Tooltip**：展示净流入 + 主力净流入明细

## 信号扫描表格（SignalTable）

### 列说明

| 列名 | 类型 | 说明 |
|------|------|------|
| 股票 | 组合列 | 公司名 + 代码 + 行业 |
| 方向 | 图标 | 做多↑绿色 / 做空↓红色 |
| 类型 | Tag | 因子/技术/基本面/事件/情绪 |
| 强度 | 文字 | 极强/强/中/弱（颜色语义） |
| 置信度 | 进度条 | 进度条颜色分级（≥80绿/≥65橙/其他红） |
| 现价 | Mono | 等宽字体 |
| 预期收益 | Mono | 带符号，颜色语义 |
| 触发因子 | Tags | 多标签展示 |
| 发现时间 | 相对时间 | Hover 显示精确时间 |
| 操作 | 按钮 | → 驾驶舱 |

### 筛选
- 类型下拉筛选
- 方向下拉筛选
- 实时显示筛选后条数

## 发现策略

| 策略 ID | 名称 | 描述 |
|---------|------|------|
| `multi_factor_v2` | 多因子选股V2 | 动量/质量/价值等多因子综合评分 |
| `technical_pattern` | 技术形态识别 | 均线/突破/量能形态模式识别 |
| `fundamental_breakout` | 基本面突破 | 盈利超预期/估值重估信号 |
| `event_driven` | 事件驱动 | 政策/公告/业绩事件触发 |
| `sector_rotation` | 板块轮动 | 行业周期轮动信号 |
