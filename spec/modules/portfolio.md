# 持仓管理 - 详细设计

## 概述

持仓管理模块提供完整的投资组合管理能力，包括持仓明细展示、多维度风险分析（因子暴露、相关性矩阵、绩效归因）和 Agent 洞察。

## 布局结构

```
┌─ Topbar 52px ──────────────────────────────────────────────┐
│ 持仓管理  │  10支持仓  最后同步  │  导入  同步券商  驾驶舱  │
└────────────────────────────────────────────────────────────┘
┌─ KPI 概览条（6项） ────────────────────────────────────────┐
│  组合净值  今日收益  YTD  超额α  夏普比率  最大回撤         │
└────────────────────────────────────────────────────────────┘
┌─ 持仓表格 flex:1 ───────────────┐ ┌─ 分析面板 340px ─────┐
│  HoldingsTable                  │ │  风险指标（2×3网格）  │
│  可展开行（持股数/日期/备注）    │ │  行业分布（进度条）   │
│                                 │ │  因子暴露（双向Bar）  │
│                                 │ │  相关性矩阵（CSS格）  │
│                                 │ │  绩效归因（Collapse） │
│                                 │ │  Agent洞察（蓝色框）  │
└─────────────────────────────────┘ └──────────────────────┘
```

## 持仓明细表格（HoldingsTable）

### 列说明

| 列名 | 类型 | 说明 |
|------|------|------|
| 股票 | 组合列 | 公司名（粗体）+ 代码 + 行业（等宽小字） |
| 权重 | 进度条+数字 | 迷你进度条 + 百分比 |
| 成本价 | Mono | 等宽字体，较低对比度 |
| 现价 | Mono | 等宽字体，较高对比度 |
| 浮盈亏 | 双行 | 上：百分比（颜色+符号）；下：金额（万元） |
| 贡献度 | Mono | 颜色语义 |
| 风险 | Rate | 1–5星，颜色区分危险度 |
| Agent信号 | Tag | buy绿/sell红/hold橙 |
| 操作 | 两个按钮 | 详情查看 + 发送至驾驶舱 |

### 展开行
点击任意行展开，显示：
- 持股数量（手/股）
- 建仓日期
- 当前市值
- 持仓备注（如有）

## 右侧分析面板（AnalysisPanel）

### 风险指标（2×3 网格）
- 夏普比率（≥1.5 绿色）
- 信息比率
- 最大回撤（红色）
- Beta 系数
- 年化波动率
- VaR 95%

### 行业分布（进度条）
- 每个行业一行：名称 + 进度条 + 权重% + 贡献%
- 进度条颜色：主色 `var(--color-accent-blue)`

### 因子暴露（G2 双向条形图）
- 6个因子：动量/价值/质量/规模/波动率/流动性
- 正值绿色条，负值红色条，居中轴对齐
- 范围 -1 到 +1

### 相关性矩阵（CSS Grid）
- 前 6 支持仓的 6×6 矩阵
- 对角线：蓝色边框（自相关=1.0）
- 正相关：绿色背景（≥0.6深绿）
- 负相关：红色背景（≤-0.4深红）
- Hover Tooltip 显示精确值

### 绩效归因（Collapse 折叠）
- 默认折叠，点击展开
- G2 横向条形图，正负颜色语义

### Agent 洞察（蓝色边框卡片）
- 固定在面板底部
- 显示 Agent 对当前组合的风险提示和操作建议
- 实际接入时通过 `POST /api/portfolio/send-to-cockpit` 触发

## KPI 概览条

| 指标 | 格式 | 颜色规则 |
|------|------|---------|
| 组合净值 | ¥XXX万 | 默认文字色 |
| 今日收益 | +X.XX% | 正绿负红 |
| YTD | +X.XX% | 正绿负红 |
| 超额收益 α | +X.XX% | 正绿负红 |
| 夏普比率 | X.XX | ≥1.5 绿色 |
| 最大回撤 | -X.XX% | 始终红色 |

## 操作功能

### 导入持仓
- 支持 CSV / Excel 格式
- 字段映射：代码/名称/数量/成本价/建仓日期
- 导入结果展示成功/跳过/错误行

### 同步券商
- 支持主流券商 API 接入（需在设置页配置凭证）
- 同步后自动更新现价和浮盈亏

### 发送至驾驶舱
- 整个组合发送：`POST /api/portfolio/send-to-cockpit`
- 单支持仓发送：`POST /api/portfolio/holdings/{id}/send-to-cockpit`
- Agent 对组合/个股进行深度分析并推送报告至工作台
